# Angular Tailwind Standards

## When to Use

- Building or refactoring Angular components and templates.
- Configuring Tailwind or shared control classes.

## Instructions

1. Prefer standalone components and signals for local state.
2. Use modern template syntax (@if/@for/@switch).
3. Use Tailwind CSS-first configuration with `@theme`.
4. Use component classes for controls, utilities for layout.
5. Add `data-testid` to interactive elements and containers.
