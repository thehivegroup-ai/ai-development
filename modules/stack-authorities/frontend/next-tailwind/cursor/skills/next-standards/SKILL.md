# Next Standards

## When to Use

- Building pages or layouts in Next.js.
- Refactoring components for server/client boundaries.

## Instructions

1. Default to Server Components; mark Client Components explicitly.
2. Use `next/link` for navigation and `next/image` for images.
3. Organize routes with App Router layouts and grouping.
4. Use Tailwind component/utility architecture for UI controls.
