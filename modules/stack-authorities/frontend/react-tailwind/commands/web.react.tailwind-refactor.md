# Web React Tailwind Refactor

Refactor UI to match Tailwind component/utility architecture.

## Steps

1. Identify controls with long inline class strings.
2. Move reusable styles into component classes.
3. Replace ad-hoc className usage with shared components.
4. Validate visual parity and accessibility.

## Guidance

- Apply `react-tailwind-conventions`.
- Ask `web.react-critic` to verify consistency.
