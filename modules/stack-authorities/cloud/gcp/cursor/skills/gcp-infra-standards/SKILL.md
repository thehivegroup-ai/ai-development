# GCP Infra Standards

## When to Use

- Planning GCP infrastructure or deployments.
- Reviewing release readiness.

## Instructions

1. Use infrastructure as code and review plans.
2. Store secrets in managed services.
3. Validate environment configuration before deploy.
4. Document rollback steps and ownership.
