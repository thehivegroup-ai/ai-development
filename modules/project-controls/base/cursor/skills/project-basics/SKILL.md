# Project Basics

## When to Use

- Preparing to finalize work or handoff.
- Reviewing a change set for baseline readiness.

## Instructions

1. Verify tests or checks were run and results are reported.
2. Check error handling and logging are consistent.
3. Ensure documentation is updated for user-facing changes.
