# Regulated Delivery

## When to Use

- Working on regulated or sensitive systems.
- Preparing for compliance reviews or audits.

## Instructions

1. Map sensitive data flows and storage locations.
2. Ensure authn/authz boundaries are explicit.
3. Confirm audit logging and tamper resistance.
4. Document risks, mitigations, and approvals.
