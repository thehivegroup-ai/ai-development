# Application Review Controls

Structured discovery and documentation of an existing application before making changes.

## Focus

- Systematic analysis of project architecture, tech stack, and conventions.
- Producing actionable context so the AI assistant can work within the project's established patterns.
- Populating project-controls with application-specific rules, skills, and agents.

## When to Use

- First time working with an unfamiliar codebase.
- Onboarding to a new project or repository.
- Before making significant changes to an application whose conventions you haven't documented yet.

## What It Produces

After running the application review, the assistant will have documented:

1. **Tech stack** -- frameworks, languages, libraries, and their versions.
2. **Project structure** -- directory layout, naming conventions, module boundaries.
3. **Patterns** -- state management, data flow, error handling, API conventions.
4. **Configuration** -- environment variables, build tools, deployment targets.
5. **Testing** -- frameworks, coverage expectations, test patterns.
6. **Dependencies** -- key third-party libraries and how they are used.
