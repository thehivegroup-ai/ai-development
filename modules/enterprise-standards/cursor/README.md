# Cursor Platform Files

This directory exists for MCP scanner compatibility.

The actual module content lives in the parent directory:
- `../agents/` - Agent definitions
- `../rules/` - Rule files
- `../skills/` - Skill definitions
- `../hooks.d/` - Hook scripts
- `../hooks.json` - Hook configuration

This structure supports the multi-platform installer pattern where content is organized at the module root level rather than under platform-specific subdirectories.
