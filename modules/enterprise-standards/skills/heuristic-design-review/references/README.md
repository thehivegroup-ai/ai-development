# Heuristic Design Review Skill - Reference Materials

This folder contains evaluation templates, anti-patterns, checklists, and examples for conducting structured design heuristic evaluations on web and mobile interfaces.

---

## Contents

### Templates
- `evaluation-template.md` - Quick-start template for conducting a full heuristic design review

### Checklists
- `visual-design-checklist.md` - Detailed checklist for evaluating visual design principles with platform-specific criteria

### Anti-Patterns
- `anti-patterns.md` - Common mistakes in design evaluation and how to avoid them

### Examples
- `example-ecommerce-checkout.md` - Complete evaluation of an e-commerce checkout flow
- `example-mobile-onboarding.md` - Mobile onboarding flow evaluation

---

## How to Use These References

1. **Running a design review?** Start with `evaluation-template.md` for structure
2. **Evaluating visual design?** Use `visual-design-checklist.md` for detailed criteria
3. **Avoiding pitfalls?** Read `anti-patterns.md` before evaluating
4. **Need an example?** See the example evaluations for complete worked examples

---

## Contributing

To add new reference materials:
1. Create markdown file with clear, structured content
2. Include evaluation context, findings, and severity ratings
3. Show specific evidence for each finding (not opinions)
4. Include platform-specific considerations where applicable
5. Always include both problems found and positive findings
