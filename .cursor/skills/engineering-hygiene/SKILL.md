# Engineering Hygiene

Use this skill to keep changes clean, testable, and review-ready.

## When to Use

- After implementing changes.
- Before declaring work ready for review or release.
- When tests or linting are failing.

## Instructions

1. Review changes for correctness and consistency.
2. Remove debug code, unused files, and temporary artifacts.
3. Run relevant tests and summarize results.
4. Check for security and performance red flags.
5. Document known gaps or follow-up tasks.
