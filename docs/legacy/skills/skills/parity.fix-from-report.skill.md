# Skill: Fix Parity From Evidence (Visual-First)

## Purpose
Fix parity gaps using **visual evidence** as the source of truth, and inventories as support.

## Procedure
1. Review `.temp/parity/diff/visual-review.html` (primary).
2. Use `.temp/parity/diff/parity-report.md` to catch copy/SEO mismatches (secondary).
3. Fix the top N highest-impact visual mismatches (avoid scope creep).
4. Follow standards:
   - `docs/standards/react.md`
   - `docs/standards/typescript.md`
   - `docs/standards/security.md`
   - `docs/standards/performance.md`
5. Re-run capture + gallery + report until visuals are acceptable or you need a human decision.

## Stop/Ask
Stop if the correct behavior is unclear or production evidence is inconsistent.
