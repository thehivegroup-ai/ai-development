- MCP server generates `hooks.claude.json` and `hooks.vscode.json`

## Final Module Structure

### Correct Source Structure

```
module-name/
├── cursor/                          # 📦 SOURCE (Cursor-specific)
│   ├── agents/                      # Agents (AGENTS.md format)
│   ├── skills/                      # Skills (Agent Skills standard)
│   ├── rules/                       # Rules (.mdc format)
│   ├── hooks/                       # Hook scripts (.sh)
│   ├── commands/                    # Commands (.md)
│   └── hooks.json                   # Hooks config
│
├── agents -> cursor/agents          # 🔗 Symlink (backward compat)
├── skills -> cursor/skills          # 🔗 Symlink (backward compat)
├── rules.cursor -> cursor/rules     # 🔗 Symlink (backward compat)
├── hooks.d -> cursor/hooks          # 🔗 Symlink (backward compat)
├── hooks.json -> cursor/hooks.json  # 🔗 Symlink (backward compat)
│
├── instructions.md                  # Platform-agnostic base
├── module.json                      # Metadata (points to cursor/)
└── README.md                        # Documentation
```

### What's NOT in Source (MCP Generates)

These are generated by MCP server during installation:
- ❌ `rules.claude/` directories
- ❌ `rules.vscode/` directories
- ❌ `instructions.vscode.md`
- ❌ `instructions.claude.md`
- ❌ `hooks.claude.json`
- ❌ `hooks.vscode.json`
